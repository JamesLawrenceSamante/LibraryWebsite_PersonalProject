# 📚 Library Login System

A library access management system that handles student check-ins with admin approval workflow and comprehensive activity logging.

## Features

- *Real-time Occupancy Counter* - Visitors can see how many people are currently inside the library
- *Student Login with Approval* - Students log in and wait for admin approval before entering
- *Admin Controls* - Approve, decline, or block student access requests
- *Activity Logs* - Complete logs for admins to track all actions and access history

## How It Works

1. Students log into the system
2. Their request goes to an admin for approval
3. Admin can accept, decline, or block the student
4. Once approved, the student can enter the library
5. Visitors can view the current occupancy count without logging in
6. All actions are logged for admin review

## Tech Stack

- Frontend: Html, CSS, JavaScript
- Backend: PHP, SQL
